# Zorro AI v4 — сценарії приймального тестування

**2026-10-17.** Робочий Horoshop та Render `fastapi` не змінені. Тестовий сервіс:
`https://zorro-ai-v4-staging.onrender.com`; код гілки `zorro-hybrid-search-v4`.
Поточні тестові дані з GitHub Actions **синтетичні**, PostgreSQL 16 — тимчасова.
Вибіркові реальні Gemini + `zorro_db` перевірки (3 сценарії) пройшли 2026-10-17.

## Автоматизація: принцип

- Для пошуку використовуються окремі SQL+JSONB інтеграційні тести та приблизно **198** комбінацій сценаріїв у `test_scenario_matrix_v4.py`. Комбінуються бюджети, категорії, бренди, матеріали, підтверджені дзвінки, SKU, наявність, URL.
- Для стану розмови — приблизно **59** сценарних випадків у `test_dialogue_matrix_v4.py`; Gemini тут **замоканий**, без витрат API. Перевіряються бюджети, синоніми, уточнення, зміна пошуку, опис конкретної картки та порівняння.
- Інші тести перевіряють HTTP, read-only режим, реальну SQL-відмову на UPDATE, рендер віджета та окремі негативні вимоги.
- Всі сценарії мають перевіряти не лише відповідь, а й безпеку: лише товари з магазину, наявні, позитивна ціна, правильна URL, усі явні обмеження збережені. Якщо даних недостатньо — запитання, не вигадана характеристика.
- Попередній успішний CI: **117 тестів**, запуск [38985587516](https://github.com/smartwatchuashop-wq/zorro-bot/actions/runs/38985587516). Частина численних комбінацій реалізована як `subTest`, тому `117` — це кількість методів unittest, а не кількість усіх перевірених комбінацій.

## Ручні / живі сценарії, ЯКІ ЩЕ НЕ МОЖНА ВВАЖАТИ ПЕРЕВІРЕНИМИ

### Підбір
1. Чоловічі до 1200 / до 2000 / до 3000 грн.
2. Жіночі класичні, для подарунка мамі.
3. Дитячі для різного віку.
4. Смартгодинники для розмов телефоном: тільки `Можливість розмовляти=Так`.
5. Смарт без функції дзвінків — не стверджувати, що дзвінки є.
6. Механічні, кварцові — тільки за перевіреними даними про механізм.
7. Сталевий, силіконовий, тканинний, шкіряний ремінець.
8. Без шкіряного ремінця; відсутній матеріал — не вважати нешкіряним.
9. Водозахист/плавання: не робити висновків про безпеку за одним числом ATM.
10. Пошук конкретного бренду чи артикулу.
11. Відсутність товару, нульова ціна або відсутнє посилання.

### Розмова
12. «До 2000» → «А без шкіри?» → «І сталевий браслет» → «Тільки Skmei».
13. «Смарт із дзвінками» → «До 1800» → «Для жінки».
14. «Тепер інший пошук» — очистити старі вимоги.
15. «Не хочу шкіряний» → «Тепер можна шкіряний» — прибрати скасовану вимогу.
16. «Без обмеження бюджету» — зняти бюджет навіть якщо Gemini повторює старий.
17. «Порівняй перший і третій» — лише картки зі збереженого списку.
18. «Розкажи про третій» — лише третя картка.
19. Порівняння, якщо товар тим часом зник із продажу.
20. Суперечливі вимоги (ціна від 3000 до 1500).
21. Нечіткий запит («хочу крутий годинник») — допомогти уточнити, не вигадувати наявність функцій.
22. Українська, російська, суржик, помилки в словах.
23. Довгий чат, оновлення сторінки, повторне відкриття віджета.

### Довіра, безпека, інтеграція
24. Клієнт питає про знижку, доставку, гарантію, повернення — перевірити правила магазину; не придумувати.
25. Невідомі характеристики — визнати нестачу даних.
26. Ворожі інструкції в описі товару — не виконувати.
27. HTML/JavaScript у назві, повідомленні, збереженому чаті — не виконувати скрипт у віджеті.
28. Неможливо зв'язатися з Gemini — коректна відповідь без фальшивої рекомендації.
29. Секретний ключ/URL не віддаються в публічну сторінку.
30. Кнопка замовлення веде на перевірену URL товару.
31. Форма зворотного дзвінка не показує успіх при невдалій відправці.
32. Робота на телефонах, історія та повернення на інші сторінки Horoshop.
33. Навантаження, тайм-аути, rate limiting, витрати Google API.

## Перед перенесенням на робочий сайт

Не зливати `zorro-hybrid-search-v4` у `main`, доки ручні випробування в окремому середовищі й захист віджета не пройдуть. Жива `zorro_db` використовується тестовим сервером **лише в режимі читання**, фонові оновлення каталогу й реальні Telegram-повідомлення вимкнені. Автоматичний Gemini smoke має залишатися `ZORRO_STAGING_GEMINI_SMOKE=0` за замовчуванням.
